# Retail-Banking-Sales-Analytics
End-to-End Banking Analytics Project using Python, SQL, Pandas, Machine Learning and Power BI.

## Project Overview
This project demonstrates an end-to-end Retail Banking Sales Analytics workflow using Python, SQL, Pandas, NumPy, Matplotlib, Scikit-learn, and Power BI.

The objective is to analyse customer banking data, identify business insights, understand customer behaviour, perform data cleaning, exploratory data analysis (EDA), SQL-based business analysis, feature engineering, customer segmentation, and build machine learning models to support business decision-making.

The project follows an industry-standard analytics workflow and is designed as a portfolio project for aspiring Data Analysts and Data Scientists.

## Business Problem
The bank wants to improve the success rate of its marketing campaigns by identifying customers who are most likely to subscribe to a term deposit. By analysing customer demographics, financial information, and previous campaign interactions, the bank can target the right customers, reduce marketing costs, and improve conversion rates.

## Project Objectives
- Understand the banking dataset and business requirements.
- Clean and preprocess the raw data.
- Perform Exploratory Data Analysis (EDA) to discover customer behaviour and business trends.
- Analyse the data using SQL to answer business questions.
- Create meaningful features for machine learning.
- Segment customers based on their characteristics.
- Build and evaluate machine learning models to predict customer subscription.
- Create interactive Power BI dashboards for business reporting.
- Provide actionable business recommendations based on data insights.

## Dataset Information
The dataset used in this project is the **Bank Marketing Dataset** from the UCI Machine Learning Repository, available on Kaggle.

### Dataset Details

- **Domain:** Banking
- **Dataset Type:** Tabular Data
- **Records:** 45,211
- **Features:** 17 Input Features + 1 Target Variable
- **Target Variable:** `y` (Whether the customer subscribed to a term deposit)

### Key Features

- Age
- Job
- Marital Status
- Education
- Balance
- Housing Loan
- Personal Loan
- Contact Type
- Campaign
- Previous Contact
- Previous Outcome
